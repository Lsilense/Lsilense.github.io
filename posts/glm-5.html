GLM-5 / GLM-5.1 技术解析：MoE 架构与智能体工程

📅 2026 年 6 月 14 日 🏷️ GLM

引言

GLM 系列在 GLM-4 之后进入了全面重构阶段。2025 年 7 月，智谱 AI 发布了首个 MoE 模型 GLM-4.5（355B 总参数 / 32B 激活），标志着 GLM 从 Dense 架构到稀疏架构的根本性转型。2026 年 2 月，GLM-5 将参数大幅扩展至 744B 总参 / 40B 激活，引入了 DeepSeek Sparse Attention、异步 RL 基础设施和长程智能体能力。随后的 GLM-5.1 在同架构基础上进一步强化了编码能力，在 SWE-Bench Pro、NL2Repo 等评测中达到开源模型顶尖水平。

本文系统解析 GLM-4.5 → GLM-5 → GLM-5.1 的演进，以及同期发布的 AutoGLM 和 GLM-Z1 在智能体工程和推理增强方向的探索。

GLM-4.5：首次 MoE 尝试

GLM-4.5（arXiv:2508.06471）是 GLM 系列的 MoE 初代产品，验证了从 Dense 到 MoE 的迁移路线。

规格

  • GLM-4.5：355B 总参数，32B 激活，MoE 架构
  • GLM-4.5-Air：106B 总参数，12B 激活
  • 上下文：128K tokens
  • 预训练：23T tokens
  • 混合推理：Think / Non-Think 双模式，通过 thinking.type 参数切换
  • MTP + EAGLE 投机解码：Multi-Token Prediction 层加速推理
  • 开源：MIT 协议，6 个变体（Base / Chat / FP8）

后训练：专家迭代 + RL

GLM-4.5 在预训练后采用了多阶段后训练管线：

  • 专家模型迭代（Expert Model Iteration）：不同领域分别训练独立的领域专家，再通过蒸馏融合回主模型
  • RL 对齐：偏好优化 + 推理场景强化学习

评测表现

  • 综合排名：开源模型第 3 位（总分 63.2）
  • TAU-Bench：70.1%
  • AIME 2024：91.0%
  • SWE-bench Verified：64.2%

GLM-5：744B 参数 MoE + DSA

GLM-5（arXiv:2602.15763）将参数规模推至 744B 总参 / 40B 激活，是 GLM 系列迄今最大的模型。

架构创新

MoE 配置：

  • 总参数：744B
  • 激活参数：40B
  • 预训练 tokens：28.5T

DeepSeek Sparse Attention (DSA)：

GLM-5 引入了 DSA 稀疏注意力机制——一个轻量级 Lightning Indexer 为每个查询 token 筛选最相关的 Top-K 个前缀 token（K=2048），主注意力仅对这 K 个位置进行计算。在 128K 上下文下，有效注意力计算量降至标准注意力的约 1.6%。GLM-5 也是继 DeepSeek V3.2 / V4 之后，第二个采用 DSA 注意力机制的主流模型。

Multi-Token Prediction + EAGLE 投机解码：

继承自 GLM-4.5 的多 token 预测训练目标，配合 EAGLE 风格的投机解码加速推理。

异步 RL 基础设施（Slime）：

GLM-5 的训练管线中引入了一项重要的工程创新——Slime 异步 RL 框架。传统 RL 训练中，模型的 Rollout 和参数更新必须串行化：Rollout 完成后才能更新模型参数，更新后再进行下一轮 Rollout。Slime 框架打破了这一约束，允许模型参数在被更新时正在进行中的 Rollout 轨迹继续使用旧参数完成，再将梯度异步回传给更新后的参数。这一设计显著提升了 Agent 训练的数据吞吐。

智能体能力

GLM-5 在智能体评测上表现突出：

  • Vending Bench 2：开源模型 #1，最终余额 $4,432
  • CC-Bench-V2：前端 / 后端 / 长程任务上均表现强劲

这些成绩源于 GLM-5 在训练中纳入了大量 Agent 轨迹数据——从网页浏览、代码编辑、API 调用到多步工具使用。模型学会了在长时间跨度内维持目标一致性、在失败时重新规划策略以及高效管理上下文窗口。

# Slime 异步 RL 简化示意
def slime_training_loop(model, rollout_env, replay_buffer):
    while True:
        # 异步请求 Rollout
        future_trajectories = rollouts_async(model, rollout_env, num_workers=64)
        # 同时更新模型参数（上一批 Rollout 的梯度）
        if replay_buffer.ready():
            gradients = compute_gradients(model, replay_buffer.sample())
            model.apply_gradients(gradients)
        # 收集完成的 Rollout
        trajectories = future_trajectories.collect()
        replay_buffer.add(trajectories)

AutoGLM：智能体工程探索

AutoGLM（arXiv:2411.00820）是智谱 AI 在智能体工程方向的独立探索，发布于 2024 年 10 月，早于 GLM-5。

架构设计

  • 基座：GLM-4.1V-9B-Thinking（视觉-语言模型）
  • 参数量：AutoGLM-Phone-9B，BF16 ~10.3GB
  • 控制方式：通过 ADB（Android）/ WebDriverAgent（iOS）控制设备
  • 规划-执行分离：通过中间接口（Intermediate Interface）将高层规划与底层执行解耦

自我进化在线课程 RL

AutoGLM 的核心训练策略是 Self-evolving Online Curriculum Reinforcement Learning：

  • 从简单任务（打开 App、点击按钮）开始训练
  • 随模型能力提升，自动增加任务难度（多步操作、跨 App 协作）
  • 在真实环境中持续 Rollout，通过成功/失败信号更新策略

评测

  • Web：55.2% VAB-WebArena-Lite，96.2% OpenTable
  • Android：36.2% AndroidLab，89.7% 中文 App 任务
  • 开源：MIT 协议

GLM-5.1：编码能力跃升

GLM-5.1 在 GLM-5 的 744B/40B 架构基础上不做改动，但通过训练策略和数据质量的优化，在编码能力上实现了大幅跃升：

  • SWE-Bench Pro：开源模型 #1
  • NL2Repo：从需求到完整仓库的代码生成，开源模型 #1
  • Terminal-Bench 2.0：终端环境下的代码操作，开源模型 #1
  • 长程任务：保持数百轮对话和数千次工具调用下的有效性

GLM-5.1 的成功说明了一个重要趋势：在架构不变的前提下，训练策略和数据质量仍是拉开模型差距的关键因素。GLM-5.1 在编码相关数据分布上的针对性优化，使其在与同架构模型（包括 GLM-5 自身）的比较中展现出了显著优势。

GLM-Z1：推理增强

GLM-Z1 系列是智谱 AI 在推理增强方向的探索，对标 DeepSeek-R1 的思路：

  • GLM-Z1-9B-0414：9B 推理模型
  • GLM-Z1-32B-0414：32B 推理模型
  • GLM-Z1-Rumination-32B-0414：带扩展沉思能力的 32B 推理模型
  • 所有版本支持 32K 原生上下文（通过 YaRN 可扩展至 128K）

GLM-Z1 系列在 GLM-4-32B 基座上通过 RL 训练增强了推理链生成能力，类似于 DeepSeek-R1 的 GRPO 训练路径，但采用了智谱自研的 RL 框架。GLM-Z1-Rumination 版本增加了「沉思」机制——模型在给出最终答案前会生成更长的内部推理链，在 AIME 等复杂推理任务上表现更佳。

总结

从 GLM-4.5 到 GLM-5.1，智谱 AI 在不到一年的时间内完成了从 Dense 到 MoE 的全面转型，并在三个关键方向持续深耕：

  • MoE 规模化：355B → 744B 总参数，32B → 40B 激活参数的持续扩展
  • 注意力进化：GQA → DSA 稀疏注意力，长上下文效率大幅提升
  • 智能体工程：Slime 异步 RL 训练框架 + AutoGLM GUI 智能体 + GLM-5.1 长程 Agent 能力

GLM-5.1 在同架构下通过训练数据优化实现编码能力大幅跃升，也说明了大模型竞赛中数据工程仍是关键的差异化因素。可以预见，GLM 系列下一阶段的核心方向将是 MoE + DSA 基座的进一步扩展，以及多模态智能体与长程 Agent 能力的深度融合。
