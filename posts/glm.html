GLM 系列技术解析：从自回归填空到追赶 GPT-4

📅 2026 年 6 月 14 日 🏷️ GLM

引言

GLM（General Language Model）是智谱 AI（Zhipu AI）与清华大学联合开发的大语言模型系列。从 2021 年的 GLM 论文到 2024 年的 GLM-4，GLM 系列经历了从学术研究到工业级产品的完整演进：GLM 提出了统一 NLU 和 NLG 的自回归填空目标；GLM-130B 以 DeepNorm 解决了千亿参数训练的稳定性难题；ChatGLM 系列将模型推向开源社区；GLM-4 则在综合能力上追赶上了 GPT-4 的水平。

本文覆盖 GLM 系列的前四个发展阶段（GLM → GLM-130B → ChatGLM → GLM-4），系统解析每一代的核心技术和演进逻辑。

GLM：自回归填空与统一预训练框架

GLM（arXiv:2103.10360）的核心贡献在于提出了一个全新的预训练框架——Autoregressive Blank Infilling (ABI)，将 NLU、条件生成和无条件生成统一到单一目标下。

Autoregressive Blank Infilling (ABI)

ABI 的思想结合了自编码和自回归的目标：从输入文本中随机 Blank 出连续的 Token 片段（类似 BERT 的 Mask），然后自回归地重构这些片段（类似 GPT 的生成）。与 T5 的 Span Corruption 不同，ABI 引入了 Span Shuffling——对短文的预测顺序进行随机排列，使模型必须捕获片段之间的依赖关系。

2D Position Encoding

ABI 的输入 Token 需要编码两种位置信息：在原文本中的位置和在跨度内的位置。GLM 引入了 2D 位置编码：

  • Position 1：在损坏文本 $\mathbf{x}_{\text{corrupt}}$ 中的位置（对 $[MASK]$ Token 为被遮蔽的位置）
  • Position 2：跨度内位置（Part A 为 0，Part B 为 1, 2, ..., $l_j$）

两种位置 ID 分别通过可学习的嵌入表投影后与输入 token 嵌入相加。在注意力计算中，Part A（损坏文本）的 Token 之间使用双向注意力，Part B（跨度内的 Token）使用因果注意力——这种混合注意力模式使得 GLM 既能像 BERT 一样捕获双向上下文，也能像 GPT 一样进行生成。

# GLM 自回归填空示意
def glm_forward(input_ids, span_masks):
    # input_ids: Part A + [MASK] tokens
    # span_masks: 标识每个 token 属于哪个跨度
    # 2D 位置编码
    pos1 = get_position_in_text(input_ids)
    pos2 = get_intra_span_position(span_masks)
    embeddings = token_embed(input_ids) + pos1_embed(pos1) + pos2_embed(pos2)
    # 混合注意力：Part A 双向，Part B 因果
    attention_mask = build_glm_mask(span_masks)  # 双向+因果混合
    hidden = transformer(embeddings, attention_mask)
    # 仅对 Part B（空白跨度）计算损失
    loss = autoregressive_loss(hidden, span_masks)
    return loss

GLM-130B：千亿参数的工程突破

GLM-130B（arXiv:2210.02414，ICLR 2023）将 GLM 架构扩展到 130B 参数，是当时少数成功训练千亿参数级模型并稳定运行的案例之一。

模型规格

  • 参数：130B，70 层，96 注意力头，隐藏维度 12,288
  • 训练数据：400B tokens（双语，中文 + 英文）
  • 优化器：AdamW，Apex O2 混合精度（FP16 前反向 + FP32 优化器状态）
  • 激活函数：GLU + GeLU
  • 位置编码：RoPE

DeepNorm：解决千亿参数稳定性

GLM-130B 的核心工程创新是 DeepNorm。在千亿参数规模下，标准 LayerNorm 方案（Pre-LN、Post-LN、Sandwich-LN）全部失败——训练在数万步后崩溃。DeepNorm 的公式为：

$$ \text{DeepNorm}(x) = \text{LayerNorm}(\alpha \cdot x + \text{Network}(x)), \quad \alpha = \sqrt{2N} $$

其中 $N$ 是 Transformer 层数（GLM-130B 中 N=70，$\alpha \approx 11.8$）。相比于 Post-LN 的残差缩放 $\alpha=1$，DeepNorm 大幅增强了残差连接的主导地位，使信号在 70 层深网络中仍能稳定传播。配合 Xavier Normal 初始化时对 FFN 和投影矩阵的 $(2N)^{-1/2}$ 缩放，GLM-130B 在 400B tokens 的训练中实现了全程零 Loss Spike。

Embedding Gradient Shrink

GLM-130B 观测到训练早期 embedding 层的梯度比其他层大了数个数量级。为此引入了 Embedding Gradient Shrink (EGS)，对 embedding 层梯度进行缩放：

$$ \nabla_{\text{emb}} \leftarrow \nabla_{\text{emb}} \cdot \alpha_{\text{egs}} $$

EGS 使得 embedding 层的更新步长与其他层保持一致，防止了 NLP 大模型训练中一个常见但不易调试的不稳定因素。

INT4 量化

GLM-130B 是首个实现 INT4 量化后性能几乎无损失的大模型。INT4 量化后的 GLM-130B 仅需约 70GB 显存（INT8 约 140GB，FP16 约 260GB），可以在 4 张 RTX 3090 Ti（24GB×4）或 8 张 RTX 2080 Ti（11GB×8）上部署。这一成果得益于 DeepNorm 训练出的权重分布更加规整，对低精度量化的容忍度更高。

ChatGLM 系列：开源对话模型

2023 年，智谱 AI 发布了多个面向对话场景的开源模型，使 GLM 技术惠及社区。

ChatGLM-6B

2023 年 3 月发布，6.2B 参数，基于 GLM 架构，在约 1T tokens 中英文语料上训练。核心特征：

  • INT4 量化：最低 6GB 显存可部署（INT8 10GB，FP16 13GB）
  • P-Tuning v2：参数高效微调，仅需训练 0.1% 的参数（PrefixEncoder），7GB 显存 @INT4
  • 后训练：SFT + Feedback Bootstrap + RLHF

ChatGLM2-6B

2023 年 6 月发布，架构改进：

  • FlashAttention：支持 32K 上下文
  • Multi-Query Attention (MQA)：推理速度提升 42%
  • MMLU 45.2%，GSM8K 25.9%

ChatGLM3-6B

2023 年 10 月发布，质的飞跃：

  • GQA (Group Query Attention)：替代 MQA，在效率和质量间取得更好平衡
  • Function Call：原生支持工具调用和 Agent 任务
  • MMLU 61.4%，GSM8K 72.3%，HumanEval 58.5%
  • C-Eval 69.0%，CMMLU 67.5%

从 ChatGLM1 到 ChatGLM3 的演进可以看到一个清晰的趋势：注意力机制逐渐向 GQA 收敛（MHA → MQA → GQA），上下文长度持续扩展（2K → 32K），Agent 能力原生集成（Function Call）。

GLM-4：追赶 GPT-4

2024 年 1 月发布的 GLM-4 是智谱 AI 的旗舰级产品，在综合能力上全面追赶 GPT-4。

架构变化

  • GQA：继承 ChatGLM3 的注意力设计，以 FFN 维度提升补偿 KV Cache 减少
  • RMSNorm + SwiGLU：替换 LayerNorm + ReLU/GeLU
  • RoPE 2D 形式：适配 GLM 的 2D 位置编码方案
  • 无 Bias 项：去除除 QKV 外的偏置项（提升长度外推能力）
  • 上下文：128K tokens（GLM-4-9B 后续支持 1M 变体）

GLM-4-9B 开源版

2024 年 6 月开源，9B 参数，在约 10T tokens 上训练，词表 150K（BPE，融合中文 token 与 cl100k_base）：

  • MMLU 74.7%，GSM8K 84.0%，HumanEval 70.1%
  • 超越同期的 Llama-3-8B
  • 另有 GLM-4-9B-Chat-1M 变体，支持百万级上下文

GLM-4 All Tools

GLM-4 的一个标志性能力是 All Tools——模型自主理解用户意图，规划复杂指令，并调用多种工具（Web 浏览器、Python 解释器、文生图模型）。这一能力使 GLM-4 在开放式任务上的表现接近 GPT-4 All Tools。

Benchmark 对比 GPT-4

  • MMLU：83.3% vs GPT-4 (0613) 86.4%
  • AlignBench（中文）：超越 GPT-4，匹配 GPT-4-Turbo
  • LongBench-Chat (128K)：87.3 vs GPT-4-Turbo 87.2，Claude 3 Opus 87.7

GLM-4 在中文场景上已经与 GPT-4 持平甚至局部超越，在英文和代码上仍有一定差距，但差距显著缩小。

总结

从 GLM 到 GLM-4 的演进展现了智谱 AI 清晰的技术路线：GLM 完成了架构创新（ABI + 2D PE）；GLM-130B 解决了千亿参数训练工程难题；ChatGLM 系列完成了技术普惠和社区验证；GLM-4 实现了产品级追赶。这四个阶段为后续 MoE 时代的 GLM-4.5 和 GLM-5 奠定了完整的架构基础和训练经验。
