GLM 系列技术解析：从自回归填空到追赶 GPT-4

📅 2026 年 6 月 14 日 🏷️ GLM

引言

GLM（General Language Model）是智谱 AI（Zhipu AI）与清华大学联合开发的大语言模型系列。从 2021 年 ACL 论文到 2024 年的 GLM-4，GLM 经历了从学术研究到工业级产品的完整演进。本文基于各个模型的论文和技术报告，系统解析每一代的架构设计。

GLM：自回归填空与统一预训练框架

📄 来源：GLM: General Language Model Pretraining with Autoregressive Blank Infilling · ACL 2022 · arXiv:2103.10360

GLM（arXiv:2103.10360，清华大学 & 智谱 AI，ACL 2022）提出 Autoregressive Blank Infilling (ABI) 预训练框架，将 NLU、条件生成和无条件生成统一到单一目标下。论文在 GLM-Base（110M）、GLM-Large（335M，1.25× BERT-Large）和 GLM-XL（~410M）三个规模上验证了方案的有效性。

Autoregressive Blank Infilling (ABI)

给定输入 $\mathbf{x} = [x_1, \dots, x_n]$，采样 $m$ 个连续文本跨度 $\{s_1, \dots, s_m\}$，每个 $s_j$ 长度为 $l_j \sim \text{Geom}(p)$。输入 $\mathbf{x}_{\text{corrupt}}$ 将这些跨度替换为 $[M]$ 标记，输出 $\mathbf{y}$ 是被随机打乱顺序后的所有跨度拼接序列：

$$ \max_{\theta} \log P_{\theta}(\mathbf{y} | \mathbf{x}_{\text{corrupt}}) = \sum_{j=1}^{m} \sum_{t=1}^{l_j} \log P_{\theta}(y_{j,t} \;|\; \mathbf{x}_{\text{corrupt}},\; \mathbf{y}_{\lt j},\; y_{j,\lt t}) $$

公式 1：ABI 训练目标 — 跨度按打乱顺序自回归生成（论文公式 2）

NLU 任务被统一建模为包含任务描述的 cloze 填空——例如将情感分类转化为输入"[CLS] 这是一部好电影。 [MASK] 正面 [MASK]"，通过自回归生成完成。这种设计使单一预训练同时覆盖 NLU 的「理解」和 NLG 的「生成」，在 SuperGLUE 等 NLU 基准上超越了 BERT-Large，在文本生成上也与 GPT-2 相当。

2D Position Encoding

ABI 的 Token 需要编码两种独立的位置信息，论文因此设计了 2D 位置编码：

  • Position 1：在损坏文本 $\mathbf{x}_{\text{corrupt}}$ 中的原始位置（Part A Token 的位置不变；Part B Token 的位置编码对应 $[M]$ 标记的原始位置）
  • Position 2：跨度内位置（Part A Token 均为 0；Part B 第 $t$ 个 Token 为 $t$）

两种位置 ID 分别通过可学习的嵌入表投影后与 token 嵌入相加。注意力掩码采用混合模式——Part A（损坏文本）的 Token 之间使用全双向注意力，Part B（空白跨度）使用从左到右的因果注意力。这种设计是 GLM 的核心架构创新，也是论文中被详细论证的关键设计点。

def glm_forward(input_ids, span_masks):
    """GLM 自回归填空（论文 Fig 2 对应实现）"""
    # 2D 位置编码
    pos_1 = position_in_text(input_ids)         # 原始文本位置
    pos_2 = intra_span_position(span_masks)     # Part A = 0, Part B = 1..l_j
    h     = token_embed(input_ids) + embed_2d(pos_1, pos_2)

    # 混合注意力掩码
    mask  = glm_attention_mask(span_masks)       # Part A 双向, Part B 因果
    h     = transformer(h, mask)

    # 仅对 Part B 计算交叉熵
    logits = lm_head(h)
    loss   = cross_entropy(logits[span_masks], targets)
    return loss

GLM-130B：千亿参数的工程突破

📄 来源：GLM-130B: An Open Bilingual Pre-trained Model · ICLR 2023 · arXiv:2210.02414

GLM-130B（arXiv:2210.02414，ICLR 2023）将 GLM 架构扩展到 130B 参数，是当时少数成功训练千亿参数级模型并稳定运行的案例之一。论文详细报告了训练中遇到的各种稳定性问题及其解决方案。

DeepNorm

论文报告了一个关键发现：在 130B 规模下，Pre-LN、Post-LN、Sandwich-LN 全部在训练早期发散。GLM-130B 因此设计了 DeepNorm：

$$ \text{DeepNorm}(x) = \text{LayerNorm}(\alpha \cdot x + \text{Network}(x)), \quad \alpha = (2N)^{1/2} $$

公式 2：DeepNorm（论文公式 3）— 放大残差连接主导地位

论文通过理论分析证明：DeepNorm 将残差连接缩放 $\alpha$ 倍后，输出方差 $\text{Var}(\mathbf{x}^L) = \alpha^{-2} + 1 - \alpha^{-2}$ 被约束在有限范围内。对于 $N=70$，$\alpha \approx 11.8$，残差项占主导地位，信号在深层网络中得以稳定传播。

Embedding Gradient Shrink (EGS)

论文在 §3.2.3 报告：训练早期 embedding 层的梯度范数比其他层大了 2–3 个数量级。为解决这个问题，论文对 embedding 梯度施加缩放：

$$ \nabla_{\text{embed}} \leftarrow \nabla_{\text{embed}} \cdot \alpha_{\text{egs}} \quad (\alpha_{\text{egs}} = 0.1) $$

公式 3：Embedding Gradient Shrink（论文公式 4）

EGS 使 embedding 层更新幅度与其他层持平，有效稳定了早期训练。论文还提到 attention score 在 FP16 下溢出的问题—DeepNorm 和特定初始化联合解决了这一问题。

INT4 量化

论文在 §5 详细报告了 INT4 量化方案。GLM-130B 是首个实现 INT4 后性能几乎无损的百亿参数模型：量化后的模型仅需约 70GB 显存（INT8 140GB, FP16 260GB）。论文归因于 DeepNorm 训练出的权重分布更加规则，对低精度量化的容忍度更高。论文对比了两种量化方法——分位数量化和绝对最大量化——并最终选择了混合方案。

ChatGLM-6B

基于 GLM 架构，在约 1T tokens 中英文语料上训练。模型权重以 INT4 量化后最低 6GB 显存可部署，支持 P-Tuning v2 参数高效微调（仅训练 PrefixEncoder 的 0.1% 参数）。后训练包括 SFT + Feedback Bootstrap + RLHF 三个步骤。

ChatGLM2-6B

引入 FlashAttention 将上下文从 2K 扩展至 32K。注意力从 MHA 切换为 Multi-Query Attention (MQA)，推理速度提升 42%。但 MQA 在质量上有明显折中——GSM8K 仅 25.9%。

ChatGLM3-6B

用 Group Query Attention (GQA) 替代 MQA——在 32 查询头中分组共享 KV 头，在效率和质量间取得更好平衡。GSM8K 从 25.9% 跃升至 72.3%，HumanEval 从 9.8% 跃升至 58.5%。引入原生 Function Call，支持 Agent 任务。从这一代起智谱选择 GQA 作为后续所有模型的默认注意力方案。

GLM-4 与 GLM-4-9B

GLM-4（完整版）与 GLM-4-9B（开源版）共享同代架构设计。GLM-4（0520 版本）报告的基准数据为：MMLU 83.3%（对比 GPT-4 0613 的 86.4%），AlignBench 中文任务超越 GPT-4，LongBench-Chat（128K 长上下文）得分 87.3（对比 GPT-4-Turbo 的 87.2）。

GLM-4-9B 开源版（2024 年 6 月）在 9B 量级报告的基准为：MMLU 74.7%，GSM8K 84.0%，HumanEval 70.1%，在多个基准上超越同期的 Llama-3-8B。

GLM-4 All Tools

GLM-4 All Tools 是 GLM-4 在开放任务上的能力扩展——模型自主理解用户意图，规划步骤，并调用 Web 浏览器、Python 解释器和文生图模型等工具。这一能力在 GLM-4 的产品发布中重点介绍，为后续 MoE 时代的 Agent 能力演进奠定了基础。

总结

从 GLM 到 GLM-4 的四个阶段，每一代的核心技术均可追溯至对应的学术论文或开源技术文档：

  • GLM（ACL 2022, arXiv:2103.10360）— ABI + 2D PE 的架构创新
  • GLM-130B（ICLR 2023, arXiv:2210.02414）— DeepNorm 训练稳定性和 INT4 量化的工程突破
  • ChatGLM（开源发布）— 注意力方案从 MHA → MQA → GQA 的收敛
  • GLM-4（产品发布 + HuggingFace 文档）— GQA + SwiGLU + 128K 上下文的产品化追赶

这四个阶段为后续 MoE 时代的 GLM-4.5 和 GLM-5 提供了完整的架构基础、训练经验与知识积累。
