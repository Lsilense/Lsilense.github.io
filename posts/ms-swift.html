ms-swift 技术解析：大模型微调部署框架

深入解析 ModelScope 社区开源的 ms-swift（Scalable lightWeight Infrastructure for Fine-Tuning）框架：覆盖 600+ 纯文本大模型与 400+ 多模态大模型的训练、推理、评测、量化与部署全链路，集成 LoRA/QLoRA 等轻量微调与 GRPO 系列强化学习算法，支持 Megatron 多维并行训练。

📄 来源：SWIFT: A Scalable lightWeight Infrastructure for Fine-Tuning · AAAI 2025 · arXiv:2408.05517 · GitHub: modelscope/ms-swift

一、背景与简介

随着大语言模型（LLM）和多模态大模型（MLLM）的快速发展，基于 Attention 的 Transformer 架构在各类传统学习任务上表现出色。文本分类、序列标注、视觉问答（VQA）、OCR 等原本需要不同模型处理的任务，现在可以基于一个基座模型完成。这种趋势使得大模型的训练与轻量微调变得尤为重要。

ms-swift（Scalable lightWeight Infrastructure for Fine-Tuning）是魔搭（ModelScope）社区推出的开源大模型微调部署框架，被 AAAI 2025 收录。截至 2026 年 6 月，已支持 600+ 纯文本大模型和 400+ 多模态大模型，覆盖从预训练、微调、人类对齐到推理、评测、量化、部署的全链路流程。GitHub 星标超过 14,500，是开源社区中最全面的微调框架之一。

框架的核心设计理念是统一抽象层——通过 Model ID 统一管理模型配置、分词器、对话模板与训练策略，用户只需切换 --model 参数即可在不同模型间无缝迁移，无需修改训练脚本。

2.1 模型管理模块

get_model_processor() 是模型入口函数，根据 Model ID 自动加载模型权重、分词器、配置。框架通过 model_type 字段自动匹配对应的模型架构（如 qwen2、llama、deepseek 等），并注入对应的对话模板（Template）和 Agent 模板。

2.2 训练器模块

Seq2SeqTrainer 继承自 HuggingFace Transformers 的 Trainer，扩展支持了自定义损失函数、梯度累积策略、 packing 技术以及多模态数据混合训练。训练器通过 TrainerFactory 统一调度，支持单卡、DDP、DeepSpeed、FSDP、Megatron 等多种后端。

2.3 轻量微调模块

框架深度集成 PEFT（Parameter-Efficient Fine-Tuning）生态，支持 12+ 种轻量微调方法：

方法原理典型适用场景
LoRA低秩适配矩阵注入 Attention 权重通用微调，显存 7B 约 13GB
QLoRA4-bit 量化 + LoRA显存受限场景，7B 约 9GB
DoRA权重分解（方向 + 幅度）低秩适配更精细的适配控制
LoRA+LoRA 差异化学习率加速收敛

LISA随机选择层进行全参数更新内存与效果平衡

3.2 SFT 指令微调

指令微调是 ms-swift 最核心的应用场景。以下是在单张 3090 上使用 LoRA 微调 Qwen3-4B 的标准命令：

ms-swift SFT 示例
CUDA_VISIBLE_DEVICES=0 \ swift sft \ --model Qwen/Qwen3-4B-Instruct-2507 \ --tuner_type lora \ --dataset 'AI-ModelScope/alpaca-gpt4-data-zh#500' \ 'AI-ModelScope/alpaca-gpt4-data-en#500' \ 'swift/self-cognition#500' \ --torch_dtype bfloat16 \ --num_train_epochs 1 \ --per_device_train_batch_size 1 \ --per_device_eval_batch_size 1 \ --learning_rate 1e-4 \ --lora_rank 8 \ --lora_alpha 32 \ --target_modules all-linear \ --gradient_accumulation_steps 16 \ --eval_steps 50 \ --save_steps 50 \ --max_length 2048 \ --output_dir output \ --warmup_ratio 0.05

关键参数含义：

  • --model：ModelScope 或 HuggingFace 模型 ID，框架自动识别架构并匹配对话模板
  • --tuner_type：微调方式，支持 lora、qlora、full（全参数）等
  • --target_modules all-linear：将所有线性层作为 LoRA 目标，比仅 Attention 层效果更优
  • --dataset：支持同时加载多个数据集，#500 表示每个数据集取 500 条

3.3 GRPO 强化学习

ms-swift 集成了丰富的 GRPO 算法族，是开源框架中 GRPO 支持最全面的方案之一：

  • GRPO（Group Relative Policy Optimization）— 组间相对策略优化，DeepSeek-R1 核心算法
  • DAPO — 动态采样策略优化
  • GSPO / SAPO / CISPO — GRPO 的多种变体
  • RLOO — REINFORCE Leave-One-Out
  • Reinforce++ — 增强版 REINFORCE
  • CHORD — 将偏好对齐与 RL 结合的混合方案

GRPO 训练支持同步和异步 vLLM 引擎推理加速，通过可扩展的奖励函数插件支持自定义 reward 逻辑，以及多轮推理 Scheduler 支持 Agent 工具调用场景。

四、显存优化技术

ms-swift 集成了多种显存优化技术，使得在消费级 GPU 上训练大模型成为可能：

4.1 序列并行

支持 Ulysses 和 Ring Attention 序列并行技术，将长序列切分到多 GPU 上计算注意力。Ulysses 可与 Ring-Attention 联合使用，序列可分片到任意数量（不限于注意力头数），大幅降低单卡显存占用。

4.2 Flash Attention 2/3

集成 Flash Attention 2/3，通过 IO 感知的精确注意力算法（tiling + 重计算）将注意力计算的时间复杂度从 $O(N^2)$ 的显存占用降低到 $O(N)$，同时加速计算。

4.3 GaLore / Q-Galore

GaLore（Gradient Low-Rank Projection）在预训练阶段将梯度投影到低秩空间，减少优化器状态的显存占用。Q-Galore 进一步结合量化，适用于资源极度受限的场景。

4.4 Liger-Kernel 与 UnSloth

提供优化后的 Triton kernel（Liger-Kernel）和内存高效的训练技巧（UnSloth），减少激活值显存并加速计算。

4.5 多模态 Packing

在训练多模态模型时，将多个样本打包到一个序列中，充分利用填充位置的算力，训练速度提升 100%+。支持文本、图像、视频、音频的混合模态数据训练。

五、Qwen 系列模型训练实践

ms-swift 对通义千问（Qwen）全系列模型提供了 Day-0 支持，从 Qwen-1.8B 到 Qwen3.6 全系列覆盖。以下针对不同 Qwen 版本给出最佳实践。

5.1 Qwen1.5 系列 Dense 模型

Qwen1.5（Qwen2 架构）采用 GQA + SwiGLU，参数规模从 0.5B 到 110B。推荐配置：

Qwen1.5-7B LoRA SFT
CUDA_VISIBLE_DEVICES=0 \ swift sft \ --model Qwen/Qwen1.5-7B-Chat \ --tuner_type lora \ --target_modules all-linear \ --lora_rank 16 \ --lora_alpha 32 \ --dataset your_dataset.jsonl \ --torch_dtype bfloat16 \ --per_device_train_batch_size 2 \ --gradient_accumulation_steps 8 \ --learning_rate 2e-4 \ --max_length 4096 \ --output_dir output/qwen1.5-7b-sft

5.2 Qwen2.5 系列多规模适配

Qwen2.5 系列包含 0.5B 到 72B 的 Dense 模型和 14B-A32B 的 MoE 模型。对于 MoE 模型，推荐使用 Megatron + Expert Parallelism 加速：

Qwen2.5-32B MoE Megatron 训练
CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7 \ swift sft \ --model Qwen/Qwen2.5-32B-A14B \ --tuner_type full \ --train_type megatron \ --tensor_parallel_size 2 \ --pipeline_parallel_size 2 \ --expert_parallel_size 2 \ --dataset your_dataset.jsonl \ --torch_dtype bfloat16 \ --per_device_train_batch_size 1 \ --gradient_accumulation_steps 4 \ --learning_rate 1e-5 \ --max_length 8192 \ --output_dir output/qwen2.5-32b-sft

5.3 Qwen3 系列 MoE 微调

Qwen3 引入了 Thinking/Non-Thinking 双模式框架和细粒度 MoE（128 专家）。ms-swift 通过 think_model 参数支持 Qwen3 的思考模式训练：

Qwen3-30B LoRA SFT
CUDA_VISIBLE_DEVICES=0,1,2,3 \ swift sft \ --model Qwen/Qwen3-30B-A3B \ --tuner_type lora \ --target_modules all-linear \ --lora_rank 16 \ --dataset your_dataset.jsonl \ --torch_dtype bfloat16 \ --per_device_train_batch_size 1 \ --gradient_accumulation_steps 4 \ --learning_rate 1e-4 \ --max_length 8192 \ --output_dir output/qwen3-30b-sft

5.4 Qwen3-VL 多模态微调

ms-swift 是多模态微调支持最全面的框架之一，支持 Qwen3-VL 的视觉语言联合微调：

Qwen3-VL-7B 多模态 SFT
CUDA_VISIBLE_DEVICES=0 \ swift sft \ --model Qwen/Qwen3-VL-7B \ --tuner_type lora \ --target_modules all-linear \ --dataset your_vlm_dataset.jsonl \ --torch_dtype bfloat16 \ --per_device_train_batch_size 1 \ --gradient_accumulation_steps 16 \ --learning_rate 1e-4 \ --lora_rank 8 \ --freeze_vit true \ --max_length 4096 \ --output_dir output/qwen3-vl-sft

多模态训练支持独立控制视觉编码器（ViT）、对齐器（Aligner）和语言模型（LLM）的可训练状态。通过 --freeze_vit true 冻结视觉编码器可大幅减少显存占用。

六、推理与部署

训练完成后，ms-swift 提供完整的推理加速与模型部署方案：

6.1 推理加速引擎

支持三种主流推理后端：vLLM（PagedAttention 显存管理）、SGLang（RadixAttention 前缀缓存）、LMDeploy（TurboMind 高效推理引擎），并提供 OpenAI 兼容接口。

vLLM 加速推理
CUDA_VISIBLE_DEVICES=0 \ swift infer \ --adapters output/vx-xxx/checkpoint-xxx \ --merge_lora true \ --infer_backend vllm \ --vllm_max_model_len 8192 \ --temperature 0 \ --max_new_tokens 2048

6.2 模型量化

支持 AWQ、GPTQ、FP8、BNB 四种量化方法。量化后的模型可直接使用 vLLM / SGLang / LMDeploy 加速推理。

6.3 模型评测

集成 EvalScope 评测后端，覆盖 100+ 评测数据集，支持纯文本和多模态模型的自动化评估。

6.4 模型导出与推送

微调完成后可通过 swift export 合入 LoRA 权重并推送至 ModelScope 或 HuggingFace Hub。

七、总结

ms-swift 作为魔搭社区的核心开源项目，具有以下突出特点：

  • 模型覆盖面广：600+ LLM + 400+ MLLM，热门模型 Day-0 支持，Qwen 全系列完整覆盖
  • 训练方法全面：从预训练到人类对齐，12+ PEFT 方法 + GRPO 算法族 + Megatron 并行
  • 消费级友好：QLoRA + Flash Attention + GaLore 等技术使单卡微调 7B 模型仅需 9GB 显存
  • 全链路覆盖：训练→推理→评测→量化→部署，一站式解决方案
  • 多模态领先：首个系统化支持 MLLM 微调的开源框架，支持视觉、音频、视频的混合模态训练
  • 统一抽象：通过 Model ID 驱动配置，用户只需更换 --model 参数即可在不同模型间迁移

ms-swift 已被 AAAI 2025 收录，是目前开源社区中支持模型最多、训练方法最全面的大模型微调框架之一。对于使用 Qwen 系列模型进行实际业务微调的开发者来说，ms-swift 提供了一条从数据准备到模型部署的完整通路。
