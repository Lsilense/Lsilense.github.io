DeepSeek-R1 技术解析：强化学习激发推理能力

📅 2026 年 6 月 12 日 🏷️ DeepSeek

引言

2025 年 1 月，DeepSeek 发布了 DeepSeek-R1 系列模型，首次系统性地验证了纯强化学习（Reinforcement Learning, RL）即可激发大语言模型的深度推理能力。这一发现挑战了"复杂推理能力必须依赖大规模人工标注数据"的传统认知。

R1 系列包含两个关键版本：R1-Zero（纯 RL，无监督数据）和DeepSeek-R1（冷启动 SFT + 多阶段 RL）。两者均基于 DeepSeek-V3-Base 模型，通过 Group Relative Policy Optimization（GRPO）算法在数学和代码等推理密集型任务上进行训练。R1-Zero 在训练过程中自发产生了自我验证、回溯纠错等高级推理行为——论文称之为"顿悟时刻"（Aha Moment）。R1 在此基础上进一步提升了输出可读性和综合能力，最终在 AIME 2024 数学推理上以 79.8% 的 pass@1 超越 OpenAI o1-0912（79.2%），且全程使用 MIT 协议开源。

更重要的是，R1 展示了推理能力的可迁移性——通过将 R1 生成的推理轨迹蒸馏到小模型（1.5B-70B），蒸馏版模型在数学推理上即可超越 GPT-4 等大模型。本文将从训练管线、RL 算法、涌现行为和蒸馏技术四个维度深入解析 DeepSeek-R1。

训练管线总览

DeepSeek-R1 的训练管线由两条路径组成。R1-Zero 路径验证了"仅靠 RL 就能产生推理能力"的假设，而 R1 路径通过引入少量冷启动数据解决了可读性和语言混合等问题，实现了实用化的推理模型。

核心算法：GRPO

R1 系列采用 Group Relative Policy Optimization（GRPO）作为 RL 算法。GRPO 是 PPO（Proximal Policy Optimization）的简化变体，核心创新在于用群体内奖励归一化替代独立的价值函数（Critic）模型，将 RL 训练的显存占用降低约一半。

算法流程

对于每个 prompt $q$，GRPO 从当前策略 $\pi_\theta$ 中采样一组 $G$ 个响应 $\{o_1, o_2, ..., o_G\}$，每个响应通过奖励函数得到分数 $r_i$。第 $i$ 个响应的优势值（Advantage）计算为组内归一化奖励：

$$ A_i = \frac{r_i - \text{mean}(\{r_1, ..., r_G\})}{\text{std}(\{r_1, ..., r_G\})} $$

GRPO 的优化目标为：

$$ \mathcal{J}_{\text{GRPO}}(\theta) = \mathbb{E}_{q \sim P(Q), \{o_i\} \sim \pi_{\theta_{\text{old}}}} \left[ \frac{1}{G} \sum_{i=1}^G \left( \min\left( \frac{\pi_\theta(o_i|q)}{\pi_{\theta_{\text{old}}}(o_i|q)} A_i, \text{clip}\left( \frac{\pi_\theta(o_i|q)}{\pi_{\theta_{\text{old}}}(o_i|q)}, 1-\epsilon, 1+\epsilon \right) A_i \right) - \beta \mathbb{D}_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}}) \right) \right] $$

其中第一项是 PPO 风格的概率比裁剪，防止单次更新过大；第二项 $\beta \mathbb{D}_{\text{KL}}$ 是对参考策略 $\pi_{\text{ref}}$ 的 KL 散度惩罚，防止策略偏离过远和奖励破解（Reward Hacking）。

GRPO 相比标准 PPO 省去了同等规模的 Critic 网络，显著降低了 RL 训练的内存开销，这对于 671B 参数的超大规模模型尤为重要。

奖励设计

R1 的奖励系统极为精简，仅包含两类信号：

  • Accuracy Reward（正确性奖励）：数学题验证最终答案是否匹配标准解；代码题通过编译和测试用例判断是否正确。奖励值为 0 或 1。
  • Format Reward（格式奖励）：强制模型将推理过程放在 <think> 标签内。这一简单的格式约束使得模型的推理链和最终答案可以明确区分。

# GRPO 简化实现
def grpo_step(policy, ref_policy, prompts, reward_fn, group_size=64):
    # 采样 G 个响应
    responses = [policy.generate(p) for p in prompts * group_size]
    # 计算奖励
    rewards = reward_fn(responses)
    # 组内归一化（按 prompt 分组）
    rewards = rewards.reshape(-1, group_size)
    advantages = (rewards - rewards.mean(-1, keepdim=True)) / rewards.std(-1, keepdim=True)
    # 计算策略梯度（含 KL 正则化）
    ratios = policy.log_prob(responses) - ref_policy.log_prob(responses)
    loss = -min(ratios * advantages, clip(ratios, 1-ε, 1+ε) * advantages)
    loss += β * kl_divergence(policy, ref_policy)
    return loss.backward()

R1-Zero：纯 RL 的「顿悟时刻」

R1-Zero 的发现极具启发性——在完全不使用任何监督数据的情况下，仅通过 GRPO 和结果正确性奖励，模型便自发学会了复杂的推理策略。

涌现的推理行为

训练过程中，R1-Zero 的思维链长度（CoT Length）持续增长，表明模型正在自动学习"多花时间思考"。更重要的是，模型发展出了以下高级推理行为：

  • 自我验证（Self-Verification）：生成部分推理后进行中间检查，确认逻辑是否自洽
  • 回溯纠错（Backtracking）：意识到当前推理方向有误时，主动回退并重新开始
  • 假设检验（Hypothesis Testing）：对多种可能的解法进行尝试和比较

这些行为在训练数据中从未被显式教导——RL 的奖励信号仅告诉模型"你的答案对不对"，而模型自己"悟出"了如何通过更复杂的思考过程来提升正确率。论文将这种现象称为「顿悟时刻」：

"During the training of R1-Zero, we observe a remarkable 'aha moment' where the model learns to allocate more thinking time to a problem by reevaluating its initial approach. This behavior is not explicitly programmed but emerges as a result of the RL training."

局限

R1-Zero 虽然推理能力强劲（AIME 2024 pass@1 达 71.0%），但存在两个主要问题：

  • 可读性差：推理链中混杂多种语言（中英混写），缺乏结构化表达
  • 通用能力不足：仅针对推理任务优化，在写作、翻译等通用任务上表现不佳

这些问题促使了 DeepSeek-R1 的诞生。

DeepSeek-R1：冷启动 + 多阶段训练

DeepSeek-R1 在 R1-Zero 的基础上增加了冷启动数据和多阶段训练，解决了纯 RL 路径的两大局限。完整的训练流程分为四个阶段：

阶段 1：冷启动 SFT

从 R1-Zero 的中间检查点中筛选出数千条高可读性的 CoT 示例，人工精选为冷启动数据集。用这些数据对 V3-Base 进行监督微调，使模型学会生成结构化、语言一致的推理过程。

阶段 2：推理导向 RL

在冷启动模型上运行与 R1-Zero 相同的 GRPO 训练，使用 Accuracy + Format 奖励。这一阶段主要提升推理正确率，维持输出的可读性。

阶段 3：拒绝采样 + 通用 SFT

利用阶段 2 的模型大规模生成推理轨迹（约 80 万条），通过拒绝采样（Rejection Sampling）只保留最终答案正确的样本。将这些高质推理数据与通用领域的 SFT 数据（写作、翻译、问答等）合并，进行第二阶段的监督微调。这一步的关键在于：推理能力通过 SFT 即可迁移到通用数据上，无需对每个通用任务单独运行 RL。

阶段 4：全场景 RL

最终阶段结合推理任务和通用任务进行多目标 RL：

  • 推理任务：继续使用 Accuracy + Format 奖励
  • 通用任务：引入人类偏好奖励模型（Reward Model），用于评估 helpfulness 和 harmlessness

知识蒸馏

DeepSeek-R1 的蒸馏实验是论文中最具实际影响力的成果之一。研究表明，通过在 R1 生成的推理轨迹上进行监督微调，参数量仅 1.5B-32B 的小模型即可获得强大的推理能力，甚至在部分数学基准上超越 GPT-4 等大模型。

蒸馏过程极为简洁：使用 R1 生成约 80 万条推理轨迹（覆盖数学、代码、科学推理等），直接在小型基座模型（Qwen-2.5 系列、Llama-3 系列）上进行 SFT，无需任何 RL 阶段。

开源与部署

DeepSeek-R1 系列模型以 MIT 协议完全开源，包含完整权重和推理代码：

  • GitHub：github.com/deepseek-ai/DeepSeek-R1
  • Hugging Face：deepseek-ai/DeepSeek-R1（完整 671B）；deepseek-ai/DeepSeek-R1-Distill-Qwen-* / DeepSeek-R1-Distill-Llama-*（蒸馏版本）
  • 推理框架：通过 SGLang 和 vLLM 支持部署，蒸馏版本可在消费级 GPU（如 RTX 4090）上运行 7B/8B 模型

总结

DeepSeek-R1 的核心贡献在于系统性地论证了强化学习可以独立激发深度推理能力，而不依赖于大规模人工标注的思维链数据。R1-Zero 的"顿悟时刻"和蒸馏实验的高效迁移，分别从训练和部署两个维度为后训练阶段的推理增强提供了新的范式。

R1 的发布也催生了 Open R1 等社区复现项目，推动了推理型 RL 训练的开源生态。蒸馏模型的强大性能——特别是 7B 级模型即可超越 GPT-4 的数学推理——使得高质量推理能力不再局限于超大模型，为更广泛的应用场景打开了可能。
