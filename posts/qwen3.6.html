Qwen3.6 / Qwen3.5 技术解析：Agentic Coding 与统一视觉-语言基座

📅 2026 年 6 月 13 日 🏷️ Qwen

引言

2026 年 2 月至 4 月，Qwen 团队密集发布了两代模型——Qwen3.5（2 月）和 Qwen3.6（4 月）。Qwen3.5 是 Qwen3 的全面架构升级，引入了统一视觉-语言基座、GDN 混合注意力架构，并将模型推向了 397B 参数级别。Qwen3.6 则在 Qwen3.5 的基础上聚焦于Agentic Coding 和 Thinking Preservation，推出了面向开发者的实际编码工作流优化的 35B-A3B MoE 和 27B Dense 模型。

两个系列加在一起，覆盖了从 0.8B 到 397B 的完整参数区间，全部以 Apache 2.0 协议开源。本文将从 Qwen3.5 的基础架构升级开始，系统解析 Qwen3.5/3.6 系列的全部核心创新。

Qwen3.5：统一视觉-语言基座

Qwen3.5 的核心定位是统一视觉-语言基础模型。与 Qwen3 时代将纯文本模型和 VL 模型分开训练不同，Qwen3.5 从预训练阶段就使用早期融合（Early Fusion）策略，在数万亿多模态 Token 上联合训练。这使得 Qwen3.5 系列在纯文本推理、代码生成和视觉理解任务上均达到或超越了 Qwen3 和 Qwen3-VL 的独立版本。

GDN + 稀疏 MoE 的高效架构

Qwen3.5 承袭了前面介绍的 Gated Delta Networks（GDN），并将其与稀疏 MoE 结合，实现了高吞吐推理。旗舰模型 Qwen3.5-397B-A17B 配置为稀疏 MoE（类似 Qwen3 的细粒度专家分割），激活参数仅 17B，但总参数达到 397B。GDN 模块在长序列场景下通过增量更新机制显著降低了注意力计算量。

百万级 Agent 强化学习

Qwen3.5 在后训练阶段实现了百万级 Agent 环境的 RL 扩展。通过构建包含渐进式复杂任务分布的大规模 Agent 训练框架，模型在工具调用、多步推理和真实环境交互等能力上得到了系统性提升。配合新一代训练基础设施（异步 RL 框架、接近 100% 的多模态训练效率），Qwen3.5 在 Agent 任务上的表现显著超越了前代。

全球语言覆盖

Qwen3.5 将多语言支持从 Qwen3 的 119 种进一步扩展至 201 种语言和方言，成为开源模型中语言覆盖最广的系列之一。

Qwen3.6：面向 Agentic Coding 的升级

Qwen3.6 是 Qwen3.5 的增量升级，核心方向是提升实际编码工作流中的体验。两个模型——Qwen3.6-35B-A3B（MoE）和 Qwen3.6-27B（Dense）——在 Qwen3.5 同规格模型的基础上，重点改进了以下能力：

Agentic Coding

Qwen3.6 在前端开发工作流和仓库级推理上做了针对性优化。模型能够更好地理解整个代码仓库的结构和跨文件的依赖关系，在生成代码时考虑现有代码库的上下文。具体提升包括：

  • 仓库级代码理解：理解多文件项目结构，跨文件推理能力更强
  • 前端工作流：在 HTML/CSS/JS 联合生成场景中的流畅性和精确度提升
  • 工具调用准确性：Agent 场景下的 Function Call 命中率和参数正确性改善

Thinking Preservation

这是 Qwen3.6 的一个创新功能——跨对话轮次保留推理上下文。在传统的对话场景中，模型的推理链（<think> 块中的内容）只在当前轮次有效，下一轮就会丢失。Thinking Preservation 将推理过程的状态和中间结论在历史中保留，使得：

  • 迭代开发：在多轮代码修改中，模型记得之前的推理结论和决策理由
  • 多步调试：调试过程中逐步积累的分析不会在每轮对话中丢失
  • 减少重复：开发者无需在每轮重新描述上下文和推理方向

这一设计显著降低了在迭代开发场景中的交互开销，是 Qwen3.6 的独特价值所在。

性能表现

Qwen3.6-35B-A3B 在 3B 激活参数下实现了极佳的推理效率，适合在消费级 GPU 上部署。Qwen3.6-27B 作为密集模型，在代码生成和 Agent 任务上展现了与更大模型竞争的性价比。

开源与部署

Qwen3.5 和 Qwen3.6 全系列以 Apache 2.0 协议开源：

  • GitHub：github.com/QwenLM/Qwen3.6
  • Hugging Face：huggingface.co/Qwen · Qwen3.6 和 Qwen3.5 全系列
  • ModelScope：modelscope.cn/organization/qwen
  • Qwen3.6-35B-A3B：3B 激活参数，适合消费级 GPU 部署，推荐 vLLM 或 SGLang
  • Qwen3.5-397B-A17B：旗舰级 MoE，推荐多 GPU 分布式部署，支持 Think/Non-Think 模式

总结

Qwen3.5 和 Qwen3.6 一起构成了 Qwen 家族在 2026 上半年的完整产品线。Qwen3.5 带来了统一视觉-语言基座、GDN 混合注意力架构和百万级 Agent RL，将开源模型的架构水平推向了新高度；Qwen3.6 则在保持架构不变的前提下，通过后训练优化聚焦于Agentic Coding 和 Thinking Preservation，提升了实际编码场景下的实用体验。

从架构演进的角度看，Qwen3.5 的 397B-A17B 旗舰 MoE 以 17B 激活参数实现了性能的进一步突破，验证了稀疏 MoE + GDN 架构在大规模部署中的效率优势。201 种语言的支持和 Apache 2.0 开源协议使得这一系列成为全球范围内最具包容性的开源模型之一。
