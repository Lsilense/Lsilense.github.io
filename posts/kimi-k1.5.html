Kimi k1.5 技术解析：强化学习激发推理能力

📅 2026 年 6 月 14 日 🏷️ Kimi

引言

2025 年 1 月，月之暗面发布了 Kimi k1.5 技术报告，提出了一个简洁而强大的强化学习框架来激发大语言模型的推理能力。与 OpenAI o1 依赖 Monte Carlo Tree Search（MCTS）、Value Function 和 Process Reward Model 的复杂管线不同，k1.5 仅需 在线策略优化 + 长度惩罚，就实现了超越 o1 的数学和编程推理能力。

k1.5 系列基于 Dense Transformer 架构，延续了 Kimi Chat 的基础设计，但将训练重心从预训练切换到强化学习驱动的推理能力提升上。本文将深入解析 k1.5 的核心技术：Online Mirror Descent 策略优化、Partial Rollout 长轨迹处理、Length Penalty，以及 Long2Short 知识蒸馏。

训练管线概览

k1.5 的训练分为四个阶段，从多模态预训练到 RL 推理增强：

  1. 视觉-语言预训练：在多样化多模态语料上联合训练
  2. Cooldown 阶段：使用合成数据强化推理能力
  3. 长上下文激活：将上下文窗口扩展至 131,072（128K）tokens
  4. 强化学习阶段：基于 Online Mirror Descent 的策略优化

核心创新集中在第 4 阶段。与 DeepSeek-R1 的 GRPO 强化学习方案相比，k1.5 采用了不同的数学框架，但目标一致——通过 RL 让模型学会更好的长程推理策略。

Online Mirror Descent：策略优化框架

k1.5 的 RL 核心是一个 Online Mirror Descent (OMD) 变体。给定训练数据集 $\mathcal{D} = \{(x_i, y_i^*)\}$，在每轮 RL 迭代中最大化以下目标：

$$ \max_{\theta} \mathbb{E}_{(x, y^*) \sim \mathcal{D}} \left[ \mathbb{E}_{(y, z) \sim \pi_{\theta}} [r(x, y, y^*)] - \tau \cdot \text{KL}(\pi_{\theta}(x) \| \pi_{\theta_i}(x)) \right] $$

其中 $\tau > 0$ 是控制 KL 正则化强度的超参数，$\pi_{\theta_i}$ 是第 $i$ 轮迭代开始时的策略（作为参考策略）。该问题的闭式解为：

$$ \pi^*(y, z | x) = \frac{\pi_{\theta_i}(y,z|x) \cdot \exp(r(x,y,y^*) / \tau)}{Z} $$

其中 $Z$ 是配分函数。实际训练中，梯度更新公式为：

$$ \nabla \mathcal{L}(\theta) = \frac{1}{K} \sum_{j=1}^{K} \left[ \nabla \log \pi_{\theta}(y_j,z_j|x) \cdot (\bar{r}(x,y_j,y^*) - \bar{r}) - \frac{\tau}{2} \nabla \left( \log \frac{\pi_{\theta}(y_j,z_j|x)}{\pi_{\theta_i}(y_j,z_j|x)} \right)^2 \right] $$

其中 $\bar{r} = \frac{1}{K} \sum_{j=1}^{K} r(x,y_j,y^*)$ 是本轮采样奖励的均值。

这个框架的关键优势在于不需要 MCTS、Value Function 或 Process Reward Model——仅依靠策略本身采样 + 结果奖励信号，简化了整个 RL 管线。

Length Penalty：控制推理长度

长链思维（Long-CoT）训练中一个关键问题是：模型在 RL 过程中倾向于生成越来越长的推理链，但更长的输出并不总是带来更好的结果。

k1.5 引入长度惩罚函数，对每个采样 $i$：

$$ \text{len\_reward}(i) = \begin{cases} \lambda & \text{if } r(x, y_i, y^*) = 1 \\ \min(0, \lambda) & \text{if } r(x, y_i, y^*) = 0 \end{cases} $$

其中：

$$ \lambda = 0.5 - \frac{\text{len}(i) - \text{min\_len}}{\text{max\_len} - \text{min\_len}} $$
  • 正确响应：鼓励更短、惩罚更长（$\lambda$ 随长度递减）
  • 错误响应：明确惩罚长响应（$min(0, \lambda)$ 始终 ≤ 0）

Length Penalty 在训练初期逐步 warm-up，避免过早压制模型探索更长的推理路径。

Partial Rollout：高效处理长轨迹

长链推理的 Rollout 可能非常耗时——一个复杂的数学推理问题可能需要生成数万 token 的思考链。如果某条轨迹中途被中断，整条轨迹的算力都会被浪费。

Partial Rollout 的设计解决了这一问题：允许长尾未完成的任务暂停，在下一轮 RL 迭代中恢复。关键实现细节：

  • 轨迹的状态（包括隐层状态、已生成的 token 序列、累计奖励）被缓存
  • 训练器持续监控进行中的轨迹，达到预设的 token budget 时暂停
  • 在下一轮迭代中，从暂停位置继续生成
  • 最终奖励在整个轨迹完成后才进行一次更新

Partial Rollout 避免了单条长轨迹阻塞整个 Rollout 过程，显著提升了训练效率，是 k1.5 能够规模化扩展到超长推理链的关键工程优化。

# Partial Rollout 简化示意
def partial_rollout(model, prompt, max_tokens_per_round, buffer):
    # 检查是否有暂停的轨迹
    if prompt in buffer:
        state = buffer.pop(prompt)
        tokens = state.tokens
    else:
        tokens = []
    # 本轮生成（限 max_tokens_per_round 长度）
    for _ in range(max_tokens_per_round):
        token = model.generate_next(tokens)
        tokens.append(token)
        if token == EOS:
            reward = compute_reward(tokens)
            return tokens, reward, done=True
    # 本轮未完成，缓存状态
    buffer[prompt] = TrajectoryState(tokens)
    return tokens, reward=None, done=False

Curriculum Sampling：分层难度课程

k1.5 在 RL 训练中还采用了 Curriculum Sampling 策略：

  • 训练数据按难度分层（简单、中等、困难）
  • 训练初期以简单和中等难度样本为主，让模型建立基本的推理能力
  • 随着训练推进，逐步增加困难样本的比例
  • 这种渐进式难度提升策略比均匀采样更稳定

Long2Short：推理知识蒸馏

长链思考（Long-CoT）虽然推理质量高，但推理成本也高。k1.5 提出了 Long2Short 蒸馏方法，将长链思考模型的知识迁移到短链模型：

  1. 在标准 RL 训练后，选择在性能与效率之间最佳平衡的 checkpoint
  2. 大幅缩减最大 Rollout 长度限制
  3. 结合 Length Penalty 在更短的 token budget 下进行第二轮 RL
  4. 模型学会在更少的推理步骤中找到正确的解法

成果：Long2Short 蒸馏后的模型在 AIME 2024 上达到 60.8（对比 GPT-4o 的 9.3），在 MATH-500 上达到 94.6，同时将推理延迟降低了一个数量级。

与 DeepSeek-R1 的对比

k1.5 与 DeepSeek-R1 在同一个月发布，两者目标一致（通过 RL 增强推理），但技术路线不同：

维度 Kimi k1.5 DeepSeek-R1
RL 算法 Online Mirror Descent GRPO (Group Relative Policy Optimization)
架构 Dense Transformer MoE (DeepSeek-V3-Base)
冷启动 合成数据 Cooldown 少量 SFT + 冷启动 RL
Token 效率 Length Penalty + Partial Rollout 语言一致性奖励 + 模板约束
蒸馏 Long2Short (on-policy RL) SFT on R1 生成数据

总结

Kimi k1.5 以简洁的 RL 框架（无需 MCTS、无需 Value Function、无需 PRM）在数学和编程推理上达到了超越 OpenAI o1 的水平。其核心贡献包括：Online Mirror Descent 策略优化框架、Partial Rollout 长轨迹工程优化、Length Penalty 推理长度控制，以及 Long2Short 推理知识蒸馏方法。

k1.5 成功验证了 Dense 架构+简单 RL 框架在推理能力激发上的巨大潜力，为后续 Kimi K2 向万亿参数 MoE 的扩展积累了关键的训练基础设施和 RL 方法论。
